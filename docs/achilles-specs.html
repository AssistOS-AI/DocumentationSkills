Skill reference

Achilles Specs

Adds AchillesAgentLib dependency resolution, runtime configuration, model-tier, and LLMAgent conventions to a project bootstrap.

Operational contract

The skill extends a GAMP bootstrap by authorizing AchillesAgentLib, placing portable dependency and runtime configuration examples inside the skill folder, requiring manual runtime overrides, and routing LLM work through LLMAgent with task metadata.

Local artifacts

  • SKILL.md and DS.md define the integration contract.
  • skill.json declares the gamp-specs dependency and portable outputs.
  • examples/depsLoader.mjs resolves AchillesAgentLib from an override, a parent checkout, or node_modules.
  • examples/runtimeConfig.mjs builds runtime defaults, task tags, model tiers, and manual overrides.

Dependencies and outputs

Declared dependencies: gamp-specs

The descriptor and catalog metadata define the outputs for this skill. Consumers must preserve the complete folder when copying it so referenced files and examples remain available.

Maintenance invariant

Achilles-specific coding rules belong in the consuming project’s DS001-coding-style.md, while the examples remain inside this portable skill folder.

See DS002 for the authoritative skill contract.
