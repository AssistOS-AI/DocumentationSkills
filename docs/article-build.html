Skill reference

Article Build

Incrementally rebuilds research articles from article-owned plans, chapters, bibliography evidence, and SVG assets.

Operational contract

The orchestrator resolves an article root, refreshes generated chapters only when dependencies change, copies and validates declared SVG assets, verifies citation support, renders the final HTML, and writes a build manifest. A second unchanged run is expected to preserve generated outputs.

Local artifacts

  • skill.mjs coordinates incremental rebuild decisions and manifest generation.
  • bibliography.mjs and referenceCatalog.mjs load references, cache source evidence, and verify citation claims.
  • renderHtml.mjs renders Markdown structures, citations, figures, bibliography entries, and print controls.
  • svgValidation.mjs validates bounds, overlap, connector geometry, and chart conventions.
  • SKILL.md, DS.md, and skill.json describe the portable workflow.

Dependencies and outputs

Declared dependencies: None declared.

The descriptor and catalog metadata define the outputs for this skill. Consumers must preserve the complete folder when copying it so referenced files and examples remain available.

Maintenance invariant

Plans and bibliography metadata under the article root are authoritative; generated chapters and HTML must not drift from those inputs.
