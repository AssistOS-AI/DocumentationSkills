Skill reference

Detect Main Behaviors

Analyzes a project to identify the small evidence-backed set of behaviors that define its primary purpose.

Operational contract

The skill traces public entry points, essential workflows, hidden mechanisms with material consequences, and project-specific invariants. It returns a structured handoff for a Main Behavior specification without editing the inspected project.

Local artifacts

  • SKILL.md defines inclusion, exclusion, evidence, confidence, and handoff rules.
  • DS.md summarizes the analysis boundary.
  • skill.json declares the analysis output and aliases.
  • examples/main-behavior-example.md demonstrates the required concrete language and handoff structure.

Dependencies and outputs

Declared dependencies: None declared.

The descriptor and catalog metadata define the outputs for this skill. Consumers must preserve the complete folder when copying it so referenced files and examples remain available.

Maintenance invariant

Complexity alone does not qualify a behavior. Every accepted behavior must have a user, functional, architectural, or project-defining consequence supported by repository evidence.
