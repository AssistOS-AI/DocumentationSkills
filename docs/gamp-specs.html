Skill reference

GAMP Specs

Creates and synchronizes repository onboarding, agent guidance, HTML documentation with a required Documentation Map and reading flow, and design specifications.

Operational contract

The skill discovers implementation and guidance, incorporates a main-behavior analysis, builds a contiguous DS set, creates navigable HTML documentation, synchronizes the skill catalog, and verifies documentation links and static-site behavior.

Every generated home page includes a Documentation Map after the project overview. The map uses one column per real main page and does not invent parent-child relationships from broad topics. In a skill catalog, every skill page is a main-page link labeled with its canonical name followed by skill; the specification entry page is included once and individual specification files are omitted. It remains a semantic table without looking like a spreadsheet: open spacing and a quiet shared surface replace boxed cell borders.

Local artifacts

  • SKILL.md and DS.md define the documentation and specification contract.
  • references/ contains structure, writing, diagram, and DS guidance.
  • scripts/ contains matrix generation, link verification, and static-site verification.
  • assets/ contains the canonical specs loader, file-size checker, and GitHub Pages marker.
  • examples/skillCatalog.mjs reads and validates catalog descriptors.

Dependencies and outputs

Declared dependencies: detect-main-behaviors

The descriptor and catalog metadata define the outputs for this skill. Consumers must preserve the complete folder when copying it so referenced files and examples remain available.

Maintenance invariant

DS specifications remain the authoritative contract, DS numbering remains contiguous, substantive behavior changes update both explanatory HTML and specifications, and the Documentation Map remains synchronized with the actual page hierarchy.
