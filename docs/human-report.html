Skill reference

Human report

Defines the final response to every user prompt in clear language.

When to use it

Use it for every final response, including questions, minor edits, blocked work, and continuations. Combine related actions into one report. Intermediate progress updates and tool calls do not each require a report.

Output

The final response contains exactly one report in the user's language between two identical <<human-report>> markers. The second marker has no slash. The report explains what was decided or changed and why it matters. It states material limits and distinguishes decisions from completed implementation. The markers are not repeated in progress messages or draft examples.

In ordinary chat, the report is the entire final response. When the caller explicitly requires workflow routing, child delegation or graph generation, the report comes first and the technical Markdown or JSON payload follows the closing marker in the same final response. Control fields stay outside the report, and an optional message field does not duplicate it. Consumers can display only the report while retaining the complete output in debug logs.
