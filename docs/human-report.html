Skill reference

Human report

Defines the final response to every user prompt in clear language.

When to use it

Use it for every final response, including questions, minor edits, blocked work, and continuations. Combine related actions into one report. Intermediate progress updates and tool calls do not each require a report.

Output

The agent encloses the entire final response in the user's language between two identical <<human-report>> text markers. The second marker has no slash. The paragraph explains what was decided or changed and why it matters. It states material limits and distinguishes a decision from completed implementation. Necessary details stay inside the markers. Required workflow JSON or routing headings retain their exact structure inside the report; human-facing fields follow the plain-language rules.
