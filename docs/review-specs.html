Skill reference

Review Specs

Performs a read-only structural, syntactic, semantic, navigation, Documentation Map, reading-flow, and terminology audit of repository documentation.

Operational contract

The review starts from onboarding and primary pages, checks the documentation hierarchy and references, evaluates DS contracts, identifies unsupported or unclear claims, and returns evidence-ranked remediation guidance without changing files.

Unless the target has an explicit small-scope exception, the structural audit requires a Documentation Map that mirrors the primary header menus exactly. It verifies matching column labels and order, matching submenu links and order, and a useful short description directly below every page link. It rejects missing, extra, duplicated, relabeled, reordered, retargeted, broken, or undescribed entries, expanded specification files, generic metadata columns, and rigid spreadsheet styling.

Local artifacts

  • SKILL.md and DS.md define the read-only review boundary.
  • references/syntax-and-flow-check.md covers structure, links, markup, diagrams, and navigation.
  • references/semantics-check.md covers terminology, clarity, evidence, and coherence.
  • examples/ contains contrasting documentation examples and an analysis example.
  • skill.json declares the review handoff.

Dependencies and outputs

Declared dependencies: None declared.

The descriptor and catalog metadata define the outputs for this skill. Consumers must preserve the complete folder when copying it so referenced files and examples remain available.

Maintenance invariant

The reviewer must preserve compliant content, treat a missing or inconsistent Documentation Map as an error, and report only evidenced defects; a later authoring workflow owns all modifications.
