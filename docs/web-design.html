Skill reference

Web Design

Desktop-first HTML and CSS interface rules for navigation, popups, forms, spacing, layering, responsiveness, and dark mode.

Interface contract

The descriptor forbids nested popups and directs the agent to separate pages or tabs. A popup that collects many fields uses a large surface between 80% and 100% of the viewport, textareas never resize, and input width follows the expected content instead of filling the page. Page padding stays moderate, around 40px, and the visible box layers stay within two or three before the design is re-checked.

Responsive and theming

The rules are desktop-first. When the user also requests a mobile version, the responsive layout is designed and verified at small widths. When dark mode is requested, both the light and dark themes are implemented and kept synchronized. SKILL.md ends with a self-check that repeats these constraints after implementation.

Portable artifacts

SKILL.md contains the design rules and DS.md describes their boundary. The skill contains no executable helper or declared dependency.
