# Web Design Design Summary

## Introduction

`web-design` supplies desktop-first rules for building and reviewing HTML and CSS interfaces.

## Core Content

The descriptor directs the agent to avoid nested popups and prefer separate pages or tabs, to scale popups to their content with a large surface for many fields, to keep textareas non-resizable, to size inputs from their expected content, to keep page padding moderate, to limit the visible box layers, and to maintain a requested responsive or dark-mode version. A self-check repeats those constraints after implementation.

The skill applies to the desktop version unless the user also asks for a mobile version, in which case the responsive layout is designed and verified too. Dark mode, when requested, is maintained together with the normal theme.

The complete folder contains `SKILL.md` and `DS.md`, with no executable helper or declared dependency.
